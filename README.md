# CFBRecruitsGame
# The SEC Football Recruiting Game

A text-based college football recruiting simulation game that lets you experience the excitement of modern college football recruiting, complete with Name, Image, and Likeness (NIL) deals and unique regional opportunities.

## Features

### Recruit Generation
- Custom name entry for recruits
- Randomized star ratings (3-5 stars)
- Dynamic attribute generation:
  - Speed (60-100)
  - Strength (60-100)
  - Awareness (60-100)

### Schools
The game features four prominent SEC schools:
- Auburn University
  - Signature Conecuh Sausage NIL deal
  - Lake Martin fishing opportunities
  - Customized NIL package
- University of Florida
  - Florida Keys fishing charters
  - Competitive NIL offerings
- University of Arkansas
  - Premium hunting and fishing packages
  - Local BBQ endorsements
  - Custom NIL deals
- University of South Carolina
  - Lake Murray fishing excursions
  - Local restaurant partnerships
  - Competitive NIL package

### NIL Packages
- Each school offers unique NIL deals ranging from $500,000 to $1,000,000
- Additional sponsor opportunities specific to each school
- Region-specific outdoor activity packages

## Installation

1. Save the game file as `CFBRecruitsGame.bat`
2. Place the file in any directory on your Windows computer
3. Double-click the file to run

## System Requirements

- Windows Operating System
- Command Prompt access
- Administrative privileges not required

## How to Play

1. Launch the game by running the batch file
2. Enter the recruit's name when prompted
3. Review the recruit's randomly generated attributes
4. Review each school's offers, including:
   - Base NIL package
   - Additional sponsorship opportunities
   - Regional perks
5. Choose a school by entering the corresponding number (1-4)
6. View the commitment announcement
7. Choose to play again or exit

## Tips

- Each playthrough generates new NIL values
- Consider the total package, including both monetary and experiential offerings
- Pay attention to the unique regional opportunities each school provides

## Known Issues

- Values reset each time the game is restarted
- No save game functionality
- Limited to four SEC schools
